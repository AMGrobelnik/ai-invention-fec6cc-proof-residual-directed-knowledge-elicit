### Key Scientific Findings
1. **Schema gap is critical**: FOLIO's domain-specific predicate vocabulary (0% schema coverage) prevents the backward chainer from constructing meaningful proof chains, causing it to default to 'Uncertain' for most examples
2. **Negative result for pipeline accuracy**: Pipeline underperforms CoT by 20.7pp on FOLIO-val, but nearly matches Logic-LM on OOD data (+0.5pp), suggesting the structured approach has merit when schema coverage is adequate
3. **Zero factual hallucination**: No LLM-affirmed predicate contradicted gold FOL annotations — the binary elicitation with text grounding is highly faithful
4. **Low provenance hallucination**: Only 1.7% of affirmed predicates were ungrounded (LLM-WORLD), indicating the cite-based grounding filter works well
5. **Calibration not significant**: Spearman ρ between hallucination risk score and correctness was not significant (|ρ| < 0.1, p > 0.27), partly because so few predicates were affirmed per example
